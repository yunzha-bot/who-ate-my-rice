# 开屏视差边缘拉伸条修复 — 2026-10-22

## 复现与根因

用户反馈鼠标靠近上下左右边缘后出现直线接缝、拉伸色带。真实Chrome复现：[修复前，鼠标移到左边缘](before/chrome-1280-1.png)。

原`opening-menu.css`在树叶移动时启用`::before`，用`border-image: foliage.webp 1 stretch`将素材最外围1像素拉伸成40px补边。补边随树叶移动后进入可见区域，形成截图中的直条。修复前浏览器回归实际失败，确认移动层存在该补边源。

## 修复

- 删除拉伸补边伪元素，以原树叶图片的轻微等比放大提供覆盖余量；余量按当前位移、摆角与视口实时计算。零位移/零摆角时比例严格为1，原始资源未修改。
- 只对前景树叶图片应用独立`scale`；父层仍负责位移/旋转，不覆盖原动画；剪裁的画外安全区改为80px。
- 保持原相机视差幅度、核心UI位置、游戏镜头与玩法。没有新依赖。
- `menuLeafCover`单元测试对左右旋转轴、正负位移/摆角和四尺寸反算视口角点，确保真实画面覆盖；未采用只检查图片外接矩形的单一证据。

## 验证与证据

`scripts/verify-menu-edges.mjs`通过本地测试页观察句柄运行原游戏，只在测试中关闭卡片Hover和风摆来隔离鼠标视差。检查中心、四条边、四角，确认移动图片覆盖视口、无拉伸补边、核心UI矩形不变；最后恢复风摆截图。边界计算允许1/64px布局舍入误差。
