# 外围几何修复复核（2026-10-03）

本页复用正式 `MapBuilder`、`DoorView`、相机定位函数及 `SceneCameraDepth`，不复制街区坐标，不遮住场景；仅提供检查视点，不接入玩法或保存地图。已有开发服务器运行时打开 `/docs/verification/EXTERIOR_GEOMETRY/review.html`。

## 已确认原因

- 正式正交相机原偏移 `(12, 14, 12)`，近裁切面为 `0.1`。相机到观察点只有 22 单位，扩大的外围跨到了相机背后。修复前右侧建筑的视空间深度约为 `-4.79～9.73`，因此被近裁切面切开；主路同样跨越裁切面。这不是宽深写反、自定义三角索引或负缩放造成的破面。
- 主路与支路顶面相差 `0.015`，过路人行道留有 `0.7` 的空隙。底板未完整支撑延长后的道路；围墙、树干、车轮和棚柱等直接使用固定 Y 坐标，部分实际离地；屋顶与主体有 `0.005` 的间隙。停车棚原位置还跨到了主路上。
- 上轮独立全景镜头比正式相机远，未能暴露正式相机的近裁切问题。本轮不把上一轮的截图当作本轮通过证据。

## 修复范围

- 道路、路口、人行道和路缘仍采用矩形 `BoxGeometry`；道路统一顶面、共边拼接，无重叠的共面路面；基底覆盖完整道路范围。修正停车区接缝及原有棚车的位置，不增加建筑。
- 支撑物按实际地表高度落地；棚柱连接棚顶，补全原长椅支撑，屋顶贴合楼体。
- 每次地图构建缓存视觉包围盒。渲染前仅检查八个角，沿相机视轴后退并扩展远裁切范围；正交画面 X/Y 比例、朝向与移动依据不变。没有关闭深度测试、隐藏问题物件、修改透明度或添加遮挡物。
