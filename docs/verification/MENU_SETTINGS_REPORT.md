# 阵营选择页右侧设置区验收 — 2026-10-15

## 范围与结果

仅调整首页声音/难度入口和必要的布局、弹出控制。按用户文字要求实施；本轮消息没有附带所述两张新参考截图，不能声称已精确对齐红框。保留当前主题、背景、两张阵营卡片和原有免责声明。

- 右侧两个90×90米白按钮纵向排列，原创SVG图标；难度入口显示现有选中档位。
- 声音入口展开原 `AudioSettingsView`，未复制音量状态或修改音频播放实现；五路滑块、静音、默认值、实时GainNode和本地持久化保留。
- 难度入口展开原 `DifficultyView` 原生单选项，使用原有值、存储、开始新局配置链；选择后关闭，重复选择当前档位也关闭。
- 两面板互斥；外部点击/ESC关闭；键盘可操作，关闭后还原入口焦点。监听只绑定一次，dispose全部注销。
- 原底部难度区不再占位。正常宽屏向左展开；1600px以下空间不足时在右侧正常流展开，1200px以下入口改为卡片上方紧凑横排，820px以下沿用原卡片单列规则。没有统一缩放页面或更改卡片内部布局。
- 使用ponytail的最小改动原则，新增一个首页展示控制类，不新增依赖、玩法状态或音频系统。

## 布局与修正证据

开工保存六种视口的两卡完整innerHTML、宽高及立绘/身份/说明区尺寸和字体；最终Chrome、Edge逐项严格相等。桌面卡片仍各438px、间隔24px、总容器900px，原选择按钮和素材不变。

布局检查发现1707×450下高声音面板可能与免责声明相交，已在唯一首页样式内加入 `max-height: min(520px, 65dvh)` 和内部滚动；短窗口再次检查与卡片、底栏矩形均不相交。还修正新按钮减少动态效果规则的选择器优先级，真实computed transition为0s。
