## 1. 操作与规则

- **F** 拾取附近最近且无遮挡的物件，每个角色最多持有1件；Ctrl/Alt/Meta组合键及可见输入控件不触发拾取。
- 持有时按住**鼠标左键**显示范围、抛物线和实际落点；当前角色持续面向落点，允许沿原规则移动，不旋转相机或改变速度。松开时锁定落点、出手方向和角色朝向，飞行不再跟随鼠标。
- **右键**取消瞄准，不丢弃物件。暂停、失焦、DEV冻结/编辑、藏身、PulseLock、眩晕等状态阻止投掷；从画布拖到UI或窗口外松开不会出手。瞄准点击不触发DEV临时角色选取。
- 花瓶、小盒子实际投出后，不论命中或落空，落地/碰撞即进入USED并移除显示，不能再拾取。不做碎片物理、伤害或耐久。
- 不锈钢盆停止飞行后经过500ms可再次拾取。物件不阻塞角色移动或新增导航障碍，也不成为HideSpot。
- 实际碰撞对手后倒地眩晕2000ms；一次飞行仅结算一次命中，投掷者不受自己的物件影响，已藏身角色不受直接投掷命中。重复命中刷新到2秒，不累加时间。
- 眩晕禁止玩家/NPC位移、进食、抓捕、搜查、门操作和再次投掷；不清零已吃进度，不重置技能冷却。原冲刺摔倒计时独立推进，不被新眩晕缩短。Human不能在眩晕期间完成抓捕。
- 暂停/DEV冻结不推进飞行、禁拾、冷却和眩晕；重开恢复36件初始物件。整页刷新沿用项目原有“新会话”规则，不是中途存档；仅刷新表现/切区不会复活已使用的物件。

## 4. 架构与碰撞边界

- `ThrowableSystem`唯一持有GROUND/HELD/FLIGHT/USED、归属、飞行、冷却及新眩晕时间，原地更新固定物件集合，重开不克隆新模型。
- `ThrowableView`管理原创低模造型、鼠标事件、实际画布矩形到NDC/相机射线到地面的转换、标记和简短提示。右键、窗口外松开、暂停/失焦均取消瞄准；销毁注销监听并释放Geometry/Material。减少动态效果偏好关闭飞行摇摆，保留必要轨迹移动。
- `CollisionWorld.traceCircleXZ`提供连续保守扫掠，读取现有静态、动态门叶和旋转家具的真实局部坐标碰撞数据；范围/障碍预览与飞行同源。角色命中采用相对运动线段-圆检测，不是落点点击或预先锁定人物。
- 帧首推进眩晕/冷却计时，两个角色完成本帧碰撞移动后才推进射弹及相对运动扫掠，再处理进食和抓捕。最终复核纠正了一帧目标位置错位；新增实际接线顺序回归先失败、修复后通过。
- **抛物线是表现，碰撞沿XZ保守处理。** 不允许从墙/关门上方抛越，低家具同样阻挡；矩形扩张角部略保守，未加入真实重力、弹跳或碎片物理。这是本轮明确的最小实现边界。
- 两阵营沿既有CharacterActionView观察已结算状态；复用220ms FALL姿态及STUN，总眩晕仍为2000ms。Human通过表现子节点倒地，DeepSeek沿既有角色表现处理，不修改碰撞脚印、GLB、动画或头发资源。
- 新命中复用原世界fall音效和轻量文字反馈，不添加音频文件、不恢复五项停用声音、不生成AI声音感知事件。瞄准范围圈只在持有且左键瞄准时显示，**不是重新启用声音圈/声纹/声音方向提示**。
