# S20 加载就绪与入局门禁：本地最小修复验收

范围：用户批准的第一轮加载阻断修复；**仅本地实现/验证，公网RC不变，S20继续BLOCKED**。时间以附带JSON的startedAt/finishedAt为准。未暂存、提交、推送、触发Actions、重新部署或创建/移动Tag、Release。

## 1. 根因与修复结果

原根因见[只读诊断](S20_EXTERNAL_BLOCKERS_DIAGNOSIS.md)：20秒整体超时直接解除加载界面，8秒音频竞速又能结束图片准备；角色下载/解析/动画初始化与入局没有共用就绪条件。本轮没有改为更长固定等待，也未修改输入系统；Global Speed冲突结论保留。

| 状态/路径 | 修复前 | 修复后 |
|---|---|---|
| 模型下载超过20秒 | 自动进入菜单，可在正式模型未完成时开局 | 只显示慢网提示，仍为downloading，不标failed，不自动放行 |
| GLTF解析 / 动画初始化 | 不向入局链报告真实阶段 | 分别报告parsing / initializing；正式ready在模型挂载、动画及头发初始化成功之后 |
| 正常入局 | 可使用等待中的临时角色 | 共用门禁要求正式角色ready、首屏图片成功及场景加载请求完成 |
| 可选音频8秒预算 | 可绕过仍在等待的图片 | 音频独立预热/超时；音频失败或未完成不阻止已满足条件的正常入局，也不能放行未就绪图片/角色 |
| 真正请求/初始化失败 | 静默留下程序化外观，提示与事实难区分 | failed保留在加载界面，提供“重新加载并重试”和明确“使用简化模式继续” |
| 等待较长 | 自动按超时降级 | 可点击继续等待，也可明确选择简化模式；没有自动降级 |
| 明确选择简化之后v6迟到 | 可在游戏中突然换成正式外观 | 作废原角色加载代次；迟到克隆释放，不挂载、不初始化该角色、不覆盖simplified |
| 暂停、重开、返回菜单 | 既有行为 | 首次准入成功后保持会话准入，不让后续表现层状态误阻断重开；简化选择保持到刷新 |

简化模式说明明确包含“程序化角色及已就绪资源”。这是用户主动接受的资源降级，不伪称完整v6已加载。仍在下载的原请求不因20秒或选择简化而擅自取消，缓存可完成，但本次角色不自动换回；要重新尝试完整模式可刷新。手动重试使用真实页面reload，不无限自动循环。

## 4. Chrome / Edge真实受控浏览器

Chrome154.0.8037.100、Edge151.0.4129.86，各10个最终独立会话，共20个。显式page.goto本轮实际本地地址并核对URL/页面标题；根路径和严格Pages子路径使用独立临时HTTP服务，不操作未知页面/进程。严格子路径服务的根`/assets/...`明确404，不用SPA回退掩盖错误路径。原5173/4173在早期存在，后来实测4173连接拒绝且两端口无监听；本轮未停止它们，也未擅自重启未知进程。后续用独立临时服务完成测试并正常关闭自身服务。

### 4.1 正常网络与未授权玩法保护

- 根路径/Pages × Chrome/Edge × 双阵营三难度，共**24个入局组合**，正式v6、动画、移动、暂停/设置/恢复通过（矩阵实按W、慢网实按D，其余键位由既有自动化覆盖）。读取实际AI控制器difficultyConfig，与现有resolveAiDifficulty逐字段相同，不只检查难度文字。
- 每组合实际5份米、每份maxProgressMs=30000，投掷眩晕3000ms；36件实际道具ID、种类、房间、X/Z与保存JSON逐项一致。没有为测试移动道具或传送角色。
- 39个实际音频分别HTTP读取并WebAudio解码，全部非空；未重新启用5个停用声音，也不把自动解码当主观试听。
- 正式包无DEV入口，Z/C/X不改变镜头；自动化覆盖既有投掷轨迹/拾取/命中/释放断言。本轮浏览器没有新增一次自然整局或完整实战投掷验收，不冒充外部真人试玩。

### 4.2 约100秒模型下载复现

使用与原诊断相同的CDP延迟180ms、下行150000字节/秒、上行60000字节/秒；独立冷缓存上下文、真实传输本地gzip资源，不只模拟定时器。

| 观察 | Chrome | Edge |
|---|---:|---:|
| v6实际ResourceTiming请求耗时 | 99.855秒 | 99.886秒 |
| 约34秒检查 | FACTION_SELECT，canStart=false，inert=true，downloading | 同左 |
| 直接调用原chooseFaction测试门禁 | 被拒绝，仍FACTION_SELECT | 同左 |
| 正式就绪移除加载层（导航时间） | 103.962秒 | 103.949秒 |
| 进入PLAYING（含既有倒计时） | 107.888秒 | 107.727秒 |
| 完成后 | v6＋动画，合法位移 | v6＋Walk动画，合法位移 |

原线上约101秒、本地约100秒的差异来自实际服务器/压缩和网络环境，不宣称秒数必须完全相同。两者都覆盖远超原20秒门槛的真实下载。记录完整downloading→parsing→initializing→ready，等待期间不标failed。

### 4.3 失败、取消、重试、主动简化

两浏览器分别在独立会话中完成：

| 场景 | 结果 |
|---|---|
| 网络请求失败 | 主动route.abort('failed')，failed阻止自动入局，明确简化后可进入Human对局 |
| 请求取消 | 主动route.abort('aborted')，failed及重试/简化入口正常，不误判为ready |
| 动画初始化失败 | 在独立浏览器CDP断点中使已解析克隆的必需动画缺失，原构造函数实际抛错；模型清理、failed、明确简化正常。未修改GLB原件或生产响应 |
| 手动重试 | 去掉仅本会话故障注入后点击真实reload按钮，完整v6重新就绪、进入DP对局 |
| 下载中主动简化 | 等待提示后点击简化，进入对局；延迟35秒的v6实际到达parse断点，仍保持simplified、无外部模型/动画，不自动换回 |
| 首屏立绘延迟15秒 | 超过原8秒预算仍禁止入局，图片完成后正常放行 |
| 可选音频失败 | 主动阻断Ogg预热，正式角色与必需资源就绪后仍能正常入局 |

临时浏览器断点、实例引用及故障注入不写进源码或dist。自动键盘事件不等于真人键盘兼容验收；不改InputManager，也不重做Global Speed扩展绕行。

### 4.4 严格Network观察，不能报告全部零异常

**本轮不能宣称Chrome/Edge Network零取消。** 最终Chrome根路径及Pages两组矩阵的功能断言全部通过，但原始“所有assets请求均无error”断言因v6 `net::ERR_ABORTED`失败，故这两组原始strict verdict为false、Chrome脚本退出非零。原JSON和汇总原样保留，没有删除或放宽断言以制造通过。

该两组同时记录HTTP200、ResourceTiming解码12,496,972字节、parsing/initializing/ready及24组合中的相应实际控制成功。其他局部会话（含故障注入、迟到解析对照）也留有v6 CDP取消观察，全部列入final-verification.json的networkObservations，不能混同主动abort与自然出现的标记。**功能通过、严格零取消不通过**分开记录，不用模型外观猜测请求是否失败，也不无依据更改加载策略或宣称历史ERR_ABORTED根因已解决。

20会话的关键assets 404为0、pageerror为0；根favicon404和Three.js既有弃用警告保留。手动重试初版临时探针在reload后丢失实例引用、迟到对照初版只依赖CDP loadingFinished的判据均曾失败；原临时记录保留，修正探针生命周期并增加真实parse观察后重新验证，不为脚本错误改生产逻辑。
