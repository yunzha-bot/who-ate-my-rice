## 2. 建立基线与实际修复

开工实际基线为 **908/908**，独立类型检查和生产构建通过。工作区已有S1/S2及最终工程收尾、首页设置改动，不是干净工作树。本轮对522个既有文件建立哈希快照，随后仅修改6个获准的既有实现/测试文件；其余516个不变，原日志字节前缀完整保留。README和新增回归/报告单独记录。

### 已证实的问题及最小修复

1. **生产DEV未完全隔离。** 旧生产预览中可实际观察到调试面板、编辑器对象及DEV入口。改为开发条件初始化场景编辑器、DEV/DEV-B面板、参数持久化绑定、安全路线绘制和AI诊断日志；生产不读取DEV-B存档，不绑定编辑器保存/选取监听，不创建暂停菜单开发切换按钮。R/M/Tab开发快捷键同时检查开发环境，生产查询参数无法打开DEV或固定种子。
2. **隐藏调试对象仍分配。** 后续复核发现生产 `DEBUG_MAP=true` 仍创建188个地图标签/标记、15组编辑锚点和30个门标签。初建及重建显式传入开发条件，MapBuilder仅跳过编辑锚点，正式15个躲藏提示保留；两浏览器最终实测上述调试数量均0、正式提示15。
3. **失焦时对局仍在推进。** 有头浏览器关闭Playwright的焦点模拟后，真实切换页签可复现PLAYING计时继续。复用已有暂停入口，失焦/隐藏时暂停，回到页面不自动继续；READY使用自身时间源并在失焦时冻结。已冻结的DEV会话和编辑器保持原有行为，不把READY接到PLAYING冻结源。
4. **无消费者的逐帧声音调试计算。** 停用的玩家声纹没有实例、生产也没有展开调试面板时，跳过只供表现/调试使用的分析。AI感知、声音距离遮挡、音频播放及事件队列消费保持不变。日志收集器关闭后仍无条件drain原事件队列，避免积压。
5. **生产预览不应提供保存端点。** 布局保存插件仅用于Vite serve；隔离预览实际POST返回404，副本地图哈希不变。没有对正式地图发测试POST。

未改变AI决策、寻路频率、30秒/400ms/5份米、难度数值、玩家技能、地图碰撞、家具、HideSpot、正式模型/动画/头发、音频素材或UI视觉。没有压缩或重新生成美术、音频，没有新增依赖。
