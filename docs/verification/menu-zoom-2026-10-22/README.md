# 开屏标签右移与缩放修复 — 2026-10-22

本轮只修用户指出的名称/身份/口号靠左、浏览器放大文字越界、缩小后字和按钮过小的问题。沿用已有手账纸张系统，无新依赖/图片/动画，不修改角色、地图、玩法数值或已确认的主卡片构图。[视觉保护口径](brand-spec.md)。

## 原因与最小修复

1. 图片卡片用vw/vh，标签字体却有20～35px等上下限、身份纸条有固定最小宽度，纸底与字的尺度不同。改为`.faction-card`作为inline-size容器，用cqw共同定义字号、padding、间隙、纸底留边，文字仍为真实DOM。
2. 开始按钮宽度上限475px、设置栏上限430px，25%时在大CSS视口中缩成小块。保留原位置及美术，改用一致的视口比例；设置详情、制作信息及页脚文字也保持相对尺寸。
3. 仅按CSS宽高触发的190px标题区/330px卡片/108px按钮紧凑布局，会在桌面放大时误触发，把开始按钮挤出屏幕。现在窄竖屏与触屏短横屏仍可使用紧凑布局，桌面等比例缩放不误切换。
4. 渲染器DPR以前只在构造时设置。resize现在读取实际devicePixelRatio，保留桌面≤2、触屏≤1.35的原画质上限；不修改homeFrustum或相机观察方向。菜单虚化随视口同比缩放，避免25%下变得异常锐利。
