# 全游戏玩家界面更新验收（2026-10-12）

## 范围与设计

用户授权全游戏UI更新，明确排除两个阵营选择卡。本轮采用“家居便签”方向：暖白、低饱和蓝绿、柔和圆角与轻阴影，重要操作突出、辅助信息弱化，避免重复Sheet角饰。复用现有DOM、状态与原生设置控件，不另建UI框架。

| 界面 | 本轮调整 |
|---|---|
| 首页 | 标题底板色调、底部操作说明；两张阵营卡结构、立绘、名称、尺寸与样式不变 |
| 加载 | 与正式界面统一配色、细进度条，保持现有真实加载阶段/超时机制 |
| HUD | 身份、目标、饭碗、进度、计时合为清晰信息卡；底部技能独立小卡 |
| 交互与进度 | 紧凑E键徽章、进食/抓捕进度条；保留人物右上位置接线 |
| 暂停/设置 | 居中纸张面板、主次按钮层级、轻量滑块排版 |
| PulseLock | 简洁面板与柔色轨道；原命中窗口坐标与逻辑不变 |
| 结算 | 独立胜负色、立绘与数据分区，保留实际胜负判断与原人物图片 |

新增样式集中于`src/game-ui.css`，顶部`--game-*`变量为配色与阴影入口。`src/main.ts`最后导入该样式，避免更改旧的共享美术变量、影响阵营卡。按ponytail最小实现原则使用局部样式覆盖，不引入依赖、不删除旧资源。

## ESC蓝框原因与修正

原`ThreeGame.togglePause()`主动调用首个按钮的`focus()`；ESC属于键盘操作，因此浏览器立即显示`:focus-visible`蓝框。现在聚焦可编程聚焦的暂停面板，不聚焦“继续游戏”。按Tab仍正常进入按钮并显示焦点，保留键盘可访问性；不是全局关闭焦点提示。
