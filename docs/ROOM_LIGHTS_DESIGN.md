# 困难区域灯光（2026-10-18，本地待人工验收）

用户批准每区墙壁开关、靠近按L、亮灯取消目标区域距离限制但仍受墙门/真实藏身遮挡，玩家和两方AI同步使用。本轮不提交、推送、部署或建Tag/Release；S20仍BLOCKED。

## 规则与接线

- 沿用`apartmentMap.ROOMS`的18个地图区域ID。2026-10-18用户批准将无墙连通的两处健身分区合成一个照明区域：复用`OPEN_ROOM_CONNECTIONS`，当前共17组照明、18个开关；地图ID/房间拓扑/导航不重构。`createRoomLightSwitches`依据原墙段和静态碰撞选取墙面安装点及可站立接近点，不移动门/家具/米点/36件道具，不新增碰撞障碍。
- 每局全关，正式对局只有困难显示开关及启用灯光规则。用户2026-10-18截图反馈原白板/黄块过于抽象，改为圆角底座、凹槽、白色立体翘板、螺钉与小型指示灯，开关状态通过翘板角度及小指示灯表达，不把整块按钮涂黄。简单/普通、菜单不显示；DEV场景编辑期间仅显示设施以便调整位置，不启用夜间或灯光玩法。
- 用户要求亮区像原白天，已移除18个暖色点光与黄色地面覆盖层。新增独立RoomDaylightView，缓存原白天半球光/方向光颜色及强度，按房间XZ范围在现有受光材质中切换局部照明；亮区恢复原白天参数，暗区保持HardNightView原月光。原材质/贴图/阴影采样保留，不把全图改白天或改变可见性；角色、家具、地面与墙面按实际表面位置受光。
- 玩家走近本区开关按L切换；不能隔墙、隔家具、远程或跨区操作。被抓捕网束缚、眩晕、真正藏身、冲刺、布网/锁芯操作、暂停/说明层/DEV冻结等不允许操作。Ctrl/Alt/Meta组合键及输入框文字输入不切灯。
- L原为DEV的IJKL右移键，只在附近开关占用该次L并持续到松键；其他调试方向键保留，远处L仍按原DEV规则，不修改正式移动键。
- 可见性只看**目标所在区域**是否开灯：目标处于亮区时取消距离限制，处于暗区时恢复5单位；观察者自己开灯不代表能照见远处暗区对手。即使亮灯也不能穿墙/关闭门/真正藏身。区域外或恰好边界按暗区，不全图揭示。
- `VisionSystem`接收只读亮区判断，在原距离/几何检测及藏身门禁内分别计算两方结果；玩家显示复用同一RoomLightSystem的目标范围规则，AI仍只收到实际可见目标。亮灯可超过原11单位默认视距；简单/普通不使用此亮区扩展。
- 关灯导致失去目击时AI当帧断开视觉，仍按原Last Seen/声音/米痕行动；玩家原1秒显示保留照常，重新开灯/看见重置，真正藏身立即隐藏。模型/手持物/影子/身体网原同步规则不变。

## AI首版（就近操作，不远程控制）

- 两方均通过玩家同一近距、遮挡、行动资格和每开关共享冷却门禁操作；所有位移仍走既有`CollisionWorld.move`，不瞬移。
- Human AI偏好开灯：本区关灯时，在开关旁可即时操作；只有PATROL/INVESTIGATE允许就近绕向开关，不为了开灯放弃CHASE/CAPTURE或正在搜查/破锁/布网。
- DP AI偏好关灯：仅本区亮且**真实看见Human威胁**时尝试，不能读取隐藏目标位置；进食、进出藏身、门操作、冲刺等原命令优先。远离开关时只允许本区近距离安全绕行，路径不能进入安全距离或缩短与可见Human的距离。
- 寻路使用现有导航与门状态，路径必须留在本区，不能穿越关闭门/家具；条件不满足就保留原命令。不是全图寻找电闸或复杂灯光规划；AI仍可能因本来的进食/藏身/搜查等任务暂不切灯。

## 参数（唯一来源GAME_CONFIG.roomLights）

| 键 | 默认值 / 单位 | 用途 |
|---|---|---|
| interactionRange | 1.5世界单位 | 玩家/AI到开关的最大交互距离 |
| toggleCooldownMs | 3000毫秒 | 同一照明区域双方/多开关共用切换间隔，既有游戏时间推进，暂停冻结 |
| aiDetourRange | 4世界单位 | AI到本区开关接近点的最大就近绕行距离 |
| aiSafeDistance | 2.5世界单位 | DP绕向开关时与可见Human的最小安全距离；同时不能比当前更接近 |

新局清空灯光和冷却；非困难不推进/使用灯光。面板几何/材质等仅表现常量，不改已验收玩法值；白天参数从原灯光捕获而非再定义玩法配置。DEV家具编辑不自动移动开关，现可单独调整墙壁开关位置；应用家具/导入布局时也检查灯位接近点，不能把开关堵在不可操作处。
