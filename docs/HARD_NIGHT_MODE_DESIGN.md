# 困难档夜间视野（2026-10-18，本地待人工验收）

## 范围与规则

2026-10-18用户批准加入困难专属区域灯光：每区实体开关，靠近按L；亮灯取消目标所在区域的玩家/AI距离限制，墙门及真正藏身仍遮挡，关灯回到下述5单位/1秒保留规则。默认全关，双方AI仅能实际走近操作，共用切换间隔；详细范围、参数与验收见[区域灯光设计](ROOM_LIGHTS_DESIGN.md)。简单/普通不受影响。下表描述暗区默认行为，不代表亮区仍受5单位限制。

| 档位 | 玩家画面 | AI视觉 | 环境 |
|---|---|---|---|
| 简单/普通 | 维持原角色显示/实际藏身规则 | 原视觉距离及墙门遮挡 | 原白天灯光和背景 |
| 困难、任一主控阵营 | 自己按原藏身规则显示；对手5单位内且无遮挡显示，超距/墙门遮挡后保留1秒再隐藏，真正藏身立即隐藏 | 两阵营Vision均受5世界单位上限，超距/墙门遮挡/真正藏身立即断目击，不享受显示延迟 | 冷蓝月光，保留环境补光，不叠黑幕 |

- 两方AI与玩家画面范围仍为5世界单位，参数为`GAME_CONFIG.difficulty.hardNightRenderRange=5`、`hardNightVisionRange=5`。用户最新批准人物延迟1秒消失，新增`hardNightHideDelayMs=1000`（毫秒，默认1000）：曾看见的对手在超距/墙门遮挡后保留模型及其当前动作/位置1秒，随后隐藏；从未看见的对手不会因延迟而出现。重新看到立即恢复并重置保留时间；真正藏身立即隐藏并清空余时。不是0.3秒淡出，也不是Last Seen快照；AI不获额外视觉或位置信息，未宣称真人平衡通过。
- AI可调规则唯一来源`GAME_CONFIG.difficulty.hardNightVisionRange=5`（世界单位，默认5）。VisionSystem接收动态上限，实际距离为原运行时距离与上限的min；不改写DEV运行时预设。选DP时Human AI的visibleTarget、选Human时DP AI的visibleHuman均来自该Vision。简单/普通无此上限。声音、米痕、Last Seen有效期及失去视线后不刷新位置的规则保持；DP是否逃跑仍由原威胁阈值决定，并非5单位内必定逃跑。
- 显示按selectedFaction而非DEV临时输入目标选择。场景编辑器为独立作者工具，打开时恢复原白天和实体可见性，不改变对局状态或AI感知数据；返回困难对局再隐藏。返回菜单、下一局简单/普通恢复原灯光颜色/强度/背景。
- 延迟由HardNightView逐帧管理，ThreeGame只传既有gameplayMs；暂停、DEV冻结、说明层期间不扣时，READY不接此计时。重开、换局、换正式观察者、离开困难模式/进入编辑器清空，不继承旧对手的显示。模型/手持物/影子/身体网共用延迟显示结果，AI搜查提示与世界浮字仍按即时视线抑制，不借显示余时泄漏额外提示。
- 角色根节点visible只作用于渲染，携带的GLB、脚圈及真实投影一起隐藏；独立接地影更新在显示门禁之后，读取同一visible。角色实体、碰撞、V抓捕、自动贴身抓捕、技能冷却、伤害控制和AI执行资格不变，不把渲染隐藏写入HideSystem。
- 手持道具增加纯表现renderVisible，与原hidden/canAct分开；随当前对手可见性一起显示/隐藏，投出后弹体正常可见，地面36件道具不变。Human只在当前看见DP时显示其身体网，玩家DP自身中网效果保留；地面网原阵营可见规则不改。
- 当前看不见Human时抑制其AI搜查扇形/轮廓表现，不取消搜查实际行为。对手不可见时世界坐标反馈只保留玩家自己XZ处消息，不用“准备投掷/吃米”等悬字钉住隐藏位置；看见对手后恢复原反馈，非定位HUD与原声音保留。
- 新HardNightView只复用原半球光/方向光，夜间背景`0x101a30`、半球光强度0.9、方向光强度0.65为视觉实现常量，不属于技能数值。不改地图、模型文件、材质贴图、音频或灯光阴影相机范围。
- 此前“困难先断视线0.8秒再藏身”只是待批建议，本轮没有并行实施，原AI藏身决策保持。

## 检查与人工验收

新增`tests/hard-night.test.mjs`执行真实Vision初始化接线、HardNightView、Three.js根节点/接地影、Throwables/CaptureNet表现及原世界反馈方法，覆盖六种阵营/档位组合、困难退出恢复、菜单/DEV编辑、遮挡、Last Seen过期、持有/飞行区分和自身提示保留。现有仿真不等同于本轮夜间真人整局；完整自动门禁结果见AGENT_LOG。

待用户刷新5173新开局，Chrome/Edge分别确认：

1. 困难Human：5单位内无遮挡时DP角色、脚圈、影子、手持物/身体网同步显形；超过5单位或被墙门遮挡后保留1秒再同步隐藏；真正藏身立即隐藏。回到范围内且无遮挡/未藏身时同步恢复并取消旧消失计时；自己/门/家具/道具可辨。
2. 困难DP：Human同样按当前视野显示/隐藏，搜查特效不泄漏不可见位置；自己中网有束缚提示，E/Space/F/投掷正常。
3. 对手不可见不等于无碰撞或免抓；声音/米痕/已投出道具可用于判断。两方各自然打一局，评价夜色亮度和盲追是否公平可玩。
4. 两种主控阵营都检查：无遮挡距离≤5单位，Human AI持续接收追逐目标，DP AI持续收到视觉威胁；超过5单位或隔墙门后停止刷新目击坐标，仍可调查既有记忆/听觉线索。可用DEV观察验证，但正式不公开调试入口。
5. 返回阵营选择改简单/普通，两方各开局：白天、对手显示、原视距全部恢复。原20秒吃米、36道具位置、盆耐久、网容量、暂停/教学/冷却冻结等回归。
6. 保留期中暂停/打开操作说明/DEV冻结，余时不减少；恢复后继续，重开/换阵营不保留旧模型。两方均测试“短暂越界又回来”不再闪断；AI即时目击结果仍在超距当帧变为不可见。
