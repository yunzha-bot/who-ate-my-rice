# 谁吃了我的米 v1.0.0-rc1

S19候选试玩版（Release Candidate），按《完整制作阶段》的里程碑命名。用户确认以带已知限制的版本发布；这是GitHub预发布，不是v1.0.0正式上线公告，目前没有正式游戏网址。

## 本次快照

- Three.js双阵营：DeepSeek娘吃完5份米获胜，Human抓捕获胜；每份30秒累计进度，保留400ms准备与中断恢复。
- 简单、普通、困难仅改变对手AI；玩家技能及既有地图规则保留。
- 花瓶、小盒子、不锈钢盆拾取与鼠标瞄准投掷；命中眩晕3秒，盆可回收，其他物品一次性消耗。
- 音量、BGM、交互反馈、盆命中音和DeepSeek娘被抓失败音；五项脚步/冲刺/开关门音效继续停用。
- 响应式阵营菜单、右侧声音/难度设置、暂停/失焦处理、Hover边界修复和DEV布局保存修复。
- 生产角色v6失败时使用程序化兜底；六个旧GLB不进入正式包，生产不启用DEV编辑器、调试入口或Z/C/X镜头快捷键。

## 本地运行和生产构建

```sh
npm ci
npm run dev
```

开发入口为 `http://127.0.0.1:5173/`。验证与预览：

```sh
npm test
npx tsc --noEmit
npm run build
npm run preview -- --host 127.0.0.1 --port 4173 --strictPort
```

只将构建产生的dist用于静态托管，不公开开发服务器或整个仓库工作目录。GitHub自动生成的源码压缩包不是可直接运行的网站包；本次不上传本机dist、未知材料或旧模型作为Release附件。

## 本次归档检查

- 全量自动化测试949/949，失败/跳过/取消0；独立TypeScript、生产构建和diff检查通过，既有大chunk提示保留。
- 330项运行源码/测试/资产保护哈希不变，package及lock仅同步根版本，依赖树不变。
- Chrome和Edge独立实例在正式预览4173确认首页显示v1.0.0-rc1，无页面异常；本轮只验证版本显示，不冒充重新完成全部对局验收。

## 已知限制与验收范围

- 自动化测试及类型/构建检查不等于自然整局、主观试听或胜率验证；本轮版本归档不修改玩法。
- 独立新手教学、连续10局QA、30局统计平衡的完整证据尚未核实；低配硬件、长时间内存/性能及部分原生缩放/全屏仍待实测，不宣称通过全部阶段Gate。
- 游戏没有对局时限，持续守点可能合法延长对局；不是保证固定分钟内结束的模式。投掷后的实际平衡仍需试玩。
- 首次部署的HTTPS、另一电脑/网络访问和子路径资源尚未验证；推荐先验证完整生产包，不能将根路径本地预览当作GitHub Pages子路径兼容证明。
- 生产构建保留既有大chunk提示。包体磁盘大小与实际压缩网络传输量分开记录，不宣称低配30FPS或零内存泄漏。
- 素材来源按开发者声明及 [来源记录](https://github.com/yunzha-bot/who-ate-my-rice/blob/v1.0.0-rc1/docs/ASSET_PROVENANCE.md) 管理：两MP3为updream生成，相关立绘/UI等按GPT生成声明，37个Ogg为项目脚本合成。仅作非商业学习、交流与娱乐，不新增通用素材许可证，不视为第三方权利免责。
