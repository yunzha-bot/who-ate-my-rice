## 2026-10-02：整体构图与正式 UI 重设计

本次在前轮工作区成果上继续实施，不是只换颜色。比较了「全景沙盘＋常驻双侧工具栏」和「住宅沙盘＋侧边任务栏」两种布局，选择后者：避免工具栏夹住世界，菜单用住宅作为右侧背景，左侧大标题，底部横向选择阵营；游戏中左侧放目标与米数，右下放技能，左下放移动操作，暂停和结算改用左侧纸面板。开发工具仍独立保留在右上。

- 游戏正交镜头的纵向可视世界范围由 14 增至 19.6，增加 40%；宽屏角色视觉中心在画面 55% 处，为左侧任务卡留白。菜单采用按地图与宽高比计算的全景取景，不改世界坐标或输入轴。
- 角色仅表现子节点宽度乘 1.35、高度乘 1.65，并补偿脚底高度；角色根节点、真实碰撞圆和 AI 距离不变。墙体表现高度乘 0.72，先创建原碰撞再降低视觉网格。家具实体与房间平面尺寸保持原值，不假称重新缩放玩法地图。

- Human 显示「还剩几份米」，DP 显示「已吃完几份米」；两者共用真实数据但拥有不同目标文案和技能结构。READY 使用独立标题、数字和说明节点，避免窄窗口竖排溢出。

## 范围

本轮只优化暖色住宅表现、角色占位外观、相机跟随和正式 HUD，不改变已验收玩法。不是 S8 开工，也不是正式 GLB 美术交付。用户集中人工验收与 Git 归档仍待单独进行。

## 修改前的问题与取舍

- 家具与墙地颜色缺少层次，家具主要依靠方块和调试文字辨认；新增床品、书本、把手、桌面小物和少量绿植，仍使用原家具根节点。
- 对局缺少独立而简洁的正式信息层；新增米数、阵营、时间、技能冷却环、准备倒计时和状态条，保留原 DEV 面板。
- 角色为单一方块，动作难读；使用程序化低多边形占位人偶表现呼吸、走路起伏、冲刺前倾和进食微动，不制作最终资产。
- 镜头直接贴随；新增仅平移的轻微跟随平滑，不改变等距角度、输入方向或角色位移。
- 门使用木色、把手与原锁芯反馈。刻意保留门叶随真实状态立即切换，未增加可能造成视觉与碰撞短暂不一致的开门缓动。

## 2026-10-02｜角色移动表现增量

`HomeAvatar` 为身体、头、双臂和双腿建立独立的纯视觉关节。角色实际移动时，双腿交替迈步、双臂反向摆动，身体略微移重心；冲刺提高步频和摆幅，仍保留前倾；停下后逐渐收回 Idle 姿势。视觉朝向按实际位移的世界 XZ 方向设目标，以帧时间平滑追赶，并用最短角差处理 90°、180° 与 ±π 交界；实际玩家和 AI 位移不等待转身。

该增量仍只修改角色子 Mesh：Gameplay 根节点、碰撞圆、输入、移动速度、导航、AI 和 `GAME_CONFIG` 均不变。两阵营玩家与 AI 共用原有 `CharacterActionView` 接线。`tests/alpha-presentation.test.mjs` 补充关节、冲刺和连续变向回归；本增量实测结果与浏览器覆盖边界记入 `docs/AGENT_LOG.md` 的对应追加记录。待用户人工验收，不建立 Git 检查点。

## 2026-10-02｜门洞几何与四边住宅外围增量

门闪烁根因是此前视觉加厚后的门扇仍占满原门洞宽度，而固定门框立柱占据墙端同一空间；刚转开约 5°，门扇就与门框实体相交。`DoorVisualGeometry.ts` 现在统一计算视觉门扇、留空、铰链和门框尺寸：立柱置于地图原有门洞内部，门扇缩窄并把铰链轴移至留有摆动余量的位置；墙体碰撞和门态接口不变。全图 18 扇门从 0° 到 90° 每隔 5° 的网格外观碰撞测试，检查门扇及五金与墙、墙帽、固定门框的实体相交。正式 `DoorSystem` 仍即时开关，未新增与权威碰撞不同步的门动画。

住宅外围在原有前、右道路的基础上补齐后、左道路、人行道和路缘；道路段在四个角按边界拼接，避免重叠共面。北侧增加错位道路标线、铺装缝、一棵小树、低矮花坛、长椅和路灯。所有新增物件仍只属于 `residential-exterior-visual-only`，不参与碰撞、射线选中或导航。关闭、45°、全开截图中的中途角度来自实际 Three.js 门 Mesh 的临时几何预览，不表示正式游戏新增缓动。实测门禁和人工验收状态见日志末尾。

## 2026-10-02｜外围街区构图修订

四边等宽道路在全景中形成「住宅孤岛」观感，因此不再沿用。现由贯穿画面的主街、偏置支路和短服务巷形成非对称路网；住宅后方有邻居公寓与联排住宅，另一侧是低矮街角商店。停车棚、汽车、自行车、行道树、花坛、长椅和路灯按入口与路口集中摆放，而非四边均匀复制。远处地面采用与场景背景相同的无光照颜色，使边界自然退入背景。所有物件仍在 `ResidentialExterior.ts` 的纯视觉根节点下，不进入碰撞、导航、门或 AI 数据。完整全景截图保存在本轮交付画面中；用户人工验收仍待确认。
