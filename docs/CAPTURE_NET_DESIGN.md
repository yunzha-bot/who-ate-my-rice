# Human捕捉网：本地实现与人工验收

2026-10-17，用户“行，开始吧”授权本地实现。不是正式发布或S20通过；没有授权Git归档或部署。数值唯一来源为GAME_CONFIG.captureNet，完整参数表见GAME_BALANCE_CONFIG.md。

## 操作和规则

- Human Q选点，鼠标显示范围和绿/红预览；左键确认，右键/Esc取消。第一次Esc仅取消网，下一次Esc仍为暂停。
- 原地600ms布置，期间不能移动或同时使用门/搜查/强破/投掷/拾取；选点时可以走动，E/Space和投掷暂交由放置模式占用。失败、取消、被砸晕不耗网CD。
- 范围3世界单位（2026-10-17用户要求扩大，由2试调为3），不能穿墙、封闭门或家具放置，不能与角色重叠；米点、实际随机出生、藏身锚点及当前出口保留禁放余量。所有可能的藏身退出位置额外用家具中心/现有交互半径的包围圆保护（扇形也保守按圆禁放，不声称精确扇形碰撞）。
- 放置成功开始20秒CD，1秒启动，永久留场（用户追加要求取消原25秒到期）。最多同时4张，待启动网也占名额；未满且CD结束可继续布置，不能覆盖/叠放旧网。Human Q卡右上角圆标显示剩余名额4→3→2→1→0，满额显示“已放满”，取消/失败不扣名额。Human视角灰色待启动、橙色启动；DP视角隐藏全部未触发地面网，触发后身上的束缚网仍显示。显示以selectedFaction信息观察者为准，DEV临时输入目标不改变可见性；隐藏不移除真实网或拆网碰撞。
- DP进入触发圈时连续扫掠截停（包括冲刺），定身5秒（2026-10-17用户追加授权，由3秒调整），不倒地、不自动判胜；中断吃米，恢复后仍走原有移动/抓捕权威。网不加入实体碰撞或导航障碍。
- 网和投掷眩晕各走原有/自身剩余计时，移动被两者的逻辑或阻断，即剩余控制取max而不相加。两者及当时冲刺摔倒控制都结束后，2秒内不再触网；投掷原来的3秒眩晕和重复命中刷新规则不变。
- DP踩中或投掷拆网只消耗对应一张并释放一个名额；多网扫掠选择移动/弹道最先接触者，不按数组顺序误取远网。DP投掷可拆待启动或启动的网（用户明确保留），比较墙/角色/所有网的首接触；砸到更近的角色或墙不拆后方网。拆网不产生砸人音效。花瓶/盒子消耗、不锈钢盆尚有耐久时按原落地延迟恢复拾取，每盆第三次投出仍能拆网但落地损坏；Human不会误拆自己的网。
- DP Q锁门仍最多同时3扇，右上角同款圆标显示剩余名额3→2→1→0；读取DoorSystem真实锁门数，破解/强破后恢复一格，不新建锁门计数或改冷却。

## AI及生命周期

- Human AI只在当前真实视觉可见、目标在6单位内时，沿自己的已有行进方向1.4单位提出落点；简单/普通/困难布网预算分别1/2/4张，提案最短间隔5000/1500/500ms，仍共用20秒技能CD。不读藏身占用、不可见实时位置、不预测目标未来位置，不向仍被网定身的目标继续布网。
- 真正看见DP中网后，简单等待1200ms、普通500ms、困难0ms再靠近；等待期间Human AI不执行移动/搜查/投掷等动作。原速度、抓捕半径及抓捕计时不改，已经在原抓捕圈内时不额外给予免抓保护。玩家控制Human不受该反应延迟影响。
- 提案仍经同一个place、地图物理合法性和600ms布置入口。物理层可拒绝重叠，但不把隐藏坐标回传AI；布置锁定真实移动。布网本身不负责AI投掷或导航规划；后续普通/困难双方AI投掷见DIFFICULTY_DESIGN.md，布网期间仍禁投掷。
- 所有时钟只由updatePlaying的玩法delta推进；暂停/说明/DEV冻结不推进网启动、CD或定身。已无网寿命时钟。未成功的选点/布置在暂停、失焦、进入编辑器、切换控制或结算时取消，已部署网保持冻结；重开/返回阵营清空全部局内状态。
- 实际应用地图变更移除旧几何上的网但不返还CD；dispose移除网的DOM、事件、材质及几何。不保存网到sceneLayout或用户本地存档。
