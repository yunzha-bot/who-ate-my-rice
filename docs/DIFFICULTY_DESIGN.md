# 三档难度与正式进食配置

2026-10-14，用户明确批准实现，并在最终发布轮确认三档真人平衡体验通过。2026-10-15用户反馈普通追捕过强、困难过快，授权调低：本轮只将Human AI的普通/困难速度倍率从0.78/0.95改为0.64/0.76，其他参数保持。新速度待集中试玩，没有统计胜率实测，不据主观体验通过宣称双方胜率相等。归档与历次验收见验收报告。

## 唯一调整入口

- 2026-10-18用户批准困难区域灯光：18区墙壁开关，靠近L切换，亮区目标取消双方玩家/AI距离限制，墙门与真正藏身仍遮挡；暗区沿用下述5单位和1秒显示保留。默认全关，双方AI按真实目击及本区开关状态择机近距操作，无远程切灯/隐藏坐标读取，简单/普通不变。参数唯一在`GAME_CONFIG.roomLights`，详见[区域灯光设计](ROOM_LIGHTS_DESIGN.md)。

- 2026-10-18用户批准仅困难的消失延迟：`GAME_CONFIG.difficulty.hardNightHideDelayMs=1000`毫秒，曾看见的对手超距/遮挡后画面保留1秒，重新看见取消旧计时；真正藏身立即隐藏。模型/手持物/阴影同步，AI即时5单位目击仍立即断开，其他档不变。暂停/说明层/DEV冻结不扣显示时间，换局清空；不新增淡出或修改AI追逐/逃跑阈值。

- 2026-10-18仅困难夜间模式，用户最新将玩家画面和两方AI视觉同步由10改为5单位：`GAME_CONFIG.difficulty.hardNightRenderRange=5`、`hardNightVisionRange=5`。选DP时Human AI收到5单位内目标，选Human时DP AI收到同范围视觉威胁；不改变DP逃跑阈值。超距/墙门遮挡/真正藏身停止目击，原声音/米痕/Last Seen规则保持，记忆不让模型穿墙显示。简单/普通白天和原视距/显示不变，困难退出到简单/普通或菜单恢复原灯光。不加入淡出，不改下表速度/能力参数，详见[夜间模式](HARD_NIGHT_MODE_DESIGN.md)，亮度与自然整局待人工验收。
- 基础配置：`src/config/gameConfig.ts` 的 `GAME_CONFIG`。不复制三份完整配置；Human主控时对手AI的简单逼近阈值及速度来自 `GAME_CONFIG.difficulty.easyDeepseekSprint`，普通速度来自 `GAME_CONFIG.difficulty.normalDeepseekMovementMultiplier`，困难速度继承基础1。
- 档位覆盖：`src/config/difficultyConfig.ts` 的 `DIFFICULTY_OVERRIDES`，类型只允许下面6＋7个字段。未列出的AI、玩家、门、听觉、地图等参数不随难度变化。
- `resolveAiDifficulty(level, playerFaction)` 在新局建立只读快照。玩家选DeepSeek时只覆盖Human AI，选Human时只覆盖DeepSeek AI；不是给玩家角色减速或缩短技能。
- 数值单位：`Ms`为毫秒，距离为世界单位，概率／倍率无量纲，计数为房间／家具件数。

## 2026-10-17追加：三档双方AI投掷与Human AI布网

- 用户明确要求两方AI投掷准头随难度上升，并确认简单也启用、准头很差。独立AIThrowableController复用ThrowableSystem拾取/投出，不修改两套主AI的追逐/逃跑/门/藏身寻路。参数集中在GAME_CONFIG.throwableAI，不扩展既有DIFFICULTY_OVERRIDES的字段白名单。
- 顺路拾取原1.2单位内、真实无遮挡道具，每300ms尝试；不跨房间找道具或改追逃路线。只向1.5～5.5单位内当前真正看见的对手出手；禁止向藏身/眩晕/禁锢目标投掷，听觉与过期位置不作为投掷坐标。
- 简单前摇1300ms、额外间隔9000ms、落点随机误差圆半径1.8；普通900ms/6500ms/1.25；困难650ms/5000ms/0.25。困难目标距离上限为6单位（简单/普通仍5.5），共用玩家物理射程6。完整字段和单位见GAME_BALANCE_CONFIG.md。误差是几何偏差，不是固定命中概率；使用可注入随机源，运行时Math.random，不声称固定出生种子能重放所有投掷随机结果。
- 开始瞄准时记录位置和随机误差，前摇中不连续跟踪；出手时以当前仍真正可见的位置修正一次落点，沿用同一份误差。简单/普通不预测；用户明确追加选择“缩小误差，并加入有限走位预判”后，困难读取前摇期间可见位置变化的平均速度，最多预测600ms（不超过实际飞行时间）/2.4单位，不读取隐藏目标、玩家输入或未来路径。投出后三档都不追踪；玩家临时变向可躲开。该共同落点刷新防止AI在前摇期间前进后、仍朝过期地面坐标扔到脚边；简单/普通参数不变。失去视野/越界/受控/接管取消并清除本次运动估计。看见AI的玩家可看到“准备投掷…”世界提示，持有物和面向沿用现有表现，不展示AI瞄准线或目标点。
- 共用现有玩法时钟，暂停/说明/冻结不推进。门交互/搜查/吃米/藏身/冲刺/布网优先，不在这些动作中叠加投掷。角色仍走原CollisionWorld移动，命中仍走飞行首碰撞；原眩晕、道具布局和盆3次耐久不变。
- 用户另要求简单Human AI少布网、慢点靠近抓捕，困难多布网。GAME_CONFIG.captureNetAI给出简单/普通/困难主动布网预算1/2/4张、提案间隔5000/1500/500ms、目视DP中网后的靠近延迟1200/500/0ms，三档使用原20秒技能CD/4张场上总上限/永久留场/5秒禁锢，不缩小玩家Human上限。中网等待只限制AI动作和移动，不改原抓捕圈或连续抓捕判定，不构成已经贴身目标的免抓保护。
- AI反应和提案时刻读取原玩法时钟，暂停/说明/冻结不推进，手动接管不受等待影响，新局清空。基础追捕速度保留原0.52/0.64/0.76；本轮“慢点靠近”通过中网后的反应延迟实现，不重复改速度。
- 本地待验收，不表示难度胜率已经平衡。人工检查三档两阵营顺路捡物、准备提示与走位可躲、准头梯度、Human AI布网数量与中网后反应、藏身/墙后不追踪、受控后有操作窗口；暂停/重开和生产DEV隔离也需试玩。定向和全量检查见本轮AGENT_LOG。

## 自动锁门的共同安全保护（本轮追加授权）

压力回归复现DeepSeek AI在浴室把自己和一份米锁在室内，吃完后不能到达门外剩余米点。用户明确追加批准修复，三档共用同一规则：仅在自动锁门前，以当前全部门状态加上拟锁门的禁止通行集合，调用现有NavigationSystem／CollisionWorld路径；所有尚未完成米点必须仍可达，任一不可达即取消本次自动锁门。已完成米点不参与，不要求米点处于同一房间。

保留原本逃跑路线、侧向证据、距离、技能冷却及锁数检查。全不可达沿用 `ALL_RICE_UNREACHABLE`，部分不可达新增 `REMAINING_RICE_UNREACHABLE`，取消后清本次pending且不反复尝试；所有目标可达的合理锁门仍会执行。仅自动锁门准入有此安全补充，不改玩家手动锁门、Human强破或PulseLock，不新增可调参数、传送、作弊开门或跳过米点。

## 正式进食

2026-10-17用户明确批准30→20秒本地试调：`RICE_MAX_PROGRESS_MS.production = 20000`，`RICE_TIMING_MODE = 'production'`，所以Vite开发入口和生产构建都实际读取 `GAME_CONFIG.rice.maxProgressMs = 20000`。两阵营三档均5份，每份20秒进度；旧30秒是历史版本，不代表本地当前值。

原有开始／中断后恢复的400ms准备、松键／移动中断、累计进度与5/5胜利判定不变。连续吃一份从按住E起至少20.4秒玩法时间，中断后须重新准备400ms，但不清零已吃进度。5份纯进度100秒，不计跑图和中断；全局30%冲刺风险仍是总进度比例，对应累计进食30秒，不是对局墙钟时间。没有新增对局时限。

`development = 5000`保留供显式测试。旧S7D轨迹回归显式使用5秒夹具，维持其既有150秒仿真预算；难度整局回归使用真正的production20秒，不能把旧夹具当成正式运行值验证。

浴室双门历史追捕夹具显式固定30000ms，保留其原本DP吃完5份结算断言；改为20秒后该固定追逐轨迹可以提前合法抓捕，不能把胜负改变等同于锁门软锁。当前20秒由六组合进食/整局及九组合追捕后合法退避可达性回归覆盖，历史30秒结果不冒充当前正式时长验证；仿真时长覆盖仅用于测试夹具，不接入正式游戏。

## 生命周期、设置与DEV-B

1. 首页原生radio组选择难度，鼠标、Tab／方向键／空格可操作。首次或损坏偏好回落EASY；本地存储键 `who-ate-my-rice-difficulty-v1`，存取失败不阻止游戏。
2. 点击阵营卡时锁定难度；暂停设置不提供难度修改入口，ESC仅显示“当前难度：简单／普通／困难”，不显示倍率或DEV覆盖说明。
3. 重新开始沿用当前档位；返回阵营选择后可以重新选择。开发模式切换主控阵营保留档位，并按新的对手应用同档AI快照，不重开对局。
4. 新局先清本局DEV覆盖，再设置难度基准。原DEV-B预设只读保留，不会刷新或新局自动应用；已有用户预设不删除、不迁移、不改写。
5. 手动加载预设或调参仍属于显式DEV行为，优先于本局难度。实际生效值及覆盖项只在DEV-B原面板核查，不进入暂停页。重新开始再次恢复难度基准，预设文件／存储仍保留。
6. 调试解锁进度／调查配额读取本局AI快照；导出AI日志记录两侧实际AI快照、难度和DEV有效Human倍率，避免只记录EASY基础值造成误解。AI日志格式既有字段保留，新增字段为可选信息。
